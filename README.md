# Orbit: Smart City Municipal Services & Civic Infrastructure Portal

A modular, accessible municipal web portal engineered using React 18, Tailwind CSS, and Vite. Orbit centralizes civic public services, emergency dispatch notices, transit scheduling, tourism guides, and citizen feedback into an integrated digital experience.

---

## Feature Modules

- **Emergency Dispatch Banner**: High-priority alert banner for rapid public notification.
- **Civic Services Directory**: Categorized service cards for licensing, utility bills, and permits.
- **Transit & Mobility**: Integrated transit route explorer and schedule tables.
- **Tourism & Culture**: Interactive points-of-interest grid with dynamic filters.
- **Municipal Departments**: Staff directory and department office contacts.
- **Citizen Feedback**: Accessible form inputs with input validation.

---

## Technology Stack

- **Framework**: React 18 (Componentized JSX)
- **Styling**: Tailwind CSS with custom theme extensions
- **Build Tool**: Vite
- **Typography & Icons**: Custom inline SVG sprites for zero external icon library overhead

---

## Getting Started

```bash
npm install
npm run dev      # Local development server
npm run build    # Production build to dist/
```
